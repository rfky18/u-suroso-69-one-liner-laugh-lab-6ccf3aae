Entry for the make.fun bounty [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae). The program writes one short funny line answering the prompt — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`.

The line:

> It was a single sock. I was doing you a favour.

It was picked by local judging: 14 candidate lines compared pairwise, both orders, with the judge's verbatim criteria and the house judge model, against each other and against 5 stock clichés. The winner beat every cliché in both orders (margins 3–4) and won the top-4 round-robin. A single sock is useless, so eating it is framed as a favour, not a crime — a deadpan twist that fits the situation and stays tight at 47 bytes.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program prints a short report to stdout and writes `out/entry.txt`. Node standard library only, no network, deterministic: two runs produce byte-identical output.
